# 归档说明

本目录保存被《AI时代学生能力培养体系（讨论稿0.6｜六块腹肌核心能力框架）》取代的能力与课程讨论稿。

## 归档原因

旧文件对“六块腹肌 / LKFJ”存在两种并行定义：

- 作为“读得懂、问得准、说得清、算得清、做得出、能负责”的六项动作；
- 作为 AI 学习体系中的通用层、应用路径与原理路径的一部分。

0.6 版统一为：**六块腹肌是完整学生发展框架中、在 AI 时代最不能外包的六项人的基础能力；AI 是贯穿六块肌肉的时代情境和能力增强工具，而非独立能力维度。**

课程模块、产品路径和具体课时将待原则层稳定后另行重建，不再以本目录的旧编号或结构作为当前口径。

## 保留价值

归档文件不是无效材料，仍可作为以下工作的素材：

- 课程单元、项目和课时设计；
- 家长沟通与低龄阶段边界；
- A/P 技术路径、产品服务与导师制的历史思考；
- 旧版“读得懂、问得准……”作为可观察学习动作的表述。
