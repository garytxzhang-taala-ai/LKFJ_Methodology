# 管理层访谈分析系统 - 使用说明

## 系统特点

这是一个真实的投资案例访谈模拟器，管理层了解业务但**没有完全深思熟虑**，会表现出不确定性和犹豫。只有在学生问对具体财务问题时才会透露定量信息，问到不涉及的内容会自然引导回相关话题。

## 标准答案库

### 📈 收入增长
- **产品1**：2026-2028年告诉抢占市场增长率12%，之后恢复到 5% 左右的市场整体增速，2028年技术突破后涨价50%
- **产品2**：2027年当年铺设新渠道，销量增加 20%，之后恢复到 4% 左右的市场整体增速
- **三大驱动**：产品1渗透率提升、产品2新渠道、产品1技术突破

### 💰 成本与利润率
- **毛利率**：2027年产品2规模化后提升到50%
- **销售费用率**：目前10% → 2027年20%（渠道期）→ 2028-2030年12%
- **研发费用率**：2026-2027年10-12% → 2028年降至8%
- **管理费用率**：目前6% → 2029年之后4%左右

### 🏗️ 资本支出
- **2026年**：300万（新生产线，产品2产能扩张）
- **2027年**：150万（维护和升级）

### 📊 税率与折现率
- **税率**：2027年前15%（高新优惠）→ 2028年后可能25%
- **WACC**：合理区间12-15%，参考值13.5%

## 使用逻辑

### ✅ 学生问对了（会得到定量数据，但语气不确定）
**示例问题：**
- "未来3年的收入增长率是多少？"
- "销售费用占收入比重会如何变化？"
- "资本支出计划是什么？"
- "毛利率的预期是多少？"
- "WACC应该设定在什么水平？"

**系统回复（带不确定语气）：**
```
---
识别结果：嗯... 2028年产品2规模化后，大概毛利率能提升到50%左右吧
分析解释：产量增加能够获得规模效应，因此毛利率提升
模型提示：2028年之后，产品2就可以应用新的毛利率 50%。
---
```

### ❌ 学生问错了（自然引导回相关话题）
**示例问题：**
- "公司的长期战略是什么？"
- "竞争优势在哪里？"
- "企业文化是什么？"
- "管理团队背景？"

**系统回复（像聊天一样引导）：**
> "嗯，战略层面确实有很多考虑... 不过说实话具体怎么落地我们也还在摸索。您如果是要做财务模型的话，可能更需要知道一些具体的数字，比如收入增长率、费用占比、资本支出这些？我这边能给您一些参考数据。"

## 核心特性

### 1. 真实的不确定性
- 管理层使用"应该"、"大概"、"可能"、"我觉得"等词
- 偶尔说"这个我也没完全算清楚"
- 语气像真实对话，不是官方宣讲

### 2. 只聊涉及的项目
- 只讨论产品1、产品2的财务数据
- 问到其他内容会自然引导回来
- 不生硬，像朋友聊天

### 3. 智能识别与分析
- 识别关键财务信息
- 分析业务含义
- 提供建模指导

## 快速开始

### 1. 配置 API Key

打开 `index.html` 文件，找到第382行左右：

```javascript
const DEEPSEEK_API_KEY = 'sk-your-api-key-here'; // TODO: 在这里填入您的 DeepSeek API Key
```

将 `'sk-your-api-key-here'` 替换为您的实际 DeepSeek API Key。

### 2. 启动服务器

```bash
cd /Users/zhangtianxing/Management
python3 -m http.server 5000
```

### 3. 访问应用

浏览器打开：`http://localhost:5000/index.html`

### 4. 开始访谈

输入访谈问题，点击"开始分析"

## 测试建议

### 测试场景1：全面访谈
输入所有关键问题，应该能获得完整的标准答案：
```
1. 未来3年收入增长预期？
2. 各产品线增长率？
3. 产品定价策略？
4. 毛利率水平和趋势？
5. 销售费用占比变化？
6. 研发投入规划？
7. 管理费用优化空间？
8. 资本支出计划？
9. 税率情况？
10. 合理的折现率？
```

### 测试场景2：模糊提问
输入战略性问题，应该只得到引导性回复：
```
1. 公司的核心竞争力是什么？
2. 行业前景如何？
3. 管理团队经验如何？
```

## 输出格式

每条有效信息会以卡片形式展示：

```
┌─────────────────────────────────┐
│ 📌 识别结果：（管理层透露的数据） │
│ 💡 分析解释：（业务含义）         │
│ 🎯 模型提示：（如何调整参数）     │
└─────────────────────────────────┘
```

## 技术架构

- **前端**：纯HTML + CSS + JavaScript（单文件应用）
- **AI模型**：DeepSeek Chat API（预设API Key）
- **部署**：Python HTTP Server（本地）
- **特色**：无需后端，无需数据库，开箱即用

## 注意事项

1. 需要在 `index.html` 中配置有效的 DeepSeek API Key（第382行左右）
2. 需要网络连接访问 DeepSeek API
3. API Key 直接写在代码中，请注意不要将包含真实 API Key 的文件上传到公共仓库
4. 首次使用建议测试标准问题，验证管理层回答是否符合预期（带不确定语气）
5. 管理层只会讨论产品1、产品2的财务数据，其他话题会自然引导
