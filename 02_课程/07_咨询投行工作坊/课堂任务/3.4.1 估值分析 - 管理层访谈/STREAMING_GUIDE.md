# 流式输出双模式系统使用指南

## ✨ 新功能：流式输出

管理层的回答现在会**像打字一样逐字显示**，更接近真实对话体验！

## 🎯 两种使用模式

### 💬 模式一：对话模式（Chatbot）

**特点：**
- 一问一答，支持连续对话
- 流式显示回复，实时逐字输出
- 保持对话上下文，可以追问
- 带闪烁光标效果 ▌

**使用场景：**
- 逐步深入了解，像真实访谈
- 需要根据回答继续追问
- 探索性问题

**使用方法：**
1. 在底部输入框输入问题
2. 点击"发送"或按 Enter
3. 观看管理层逐字回复（带打字效果）
4. 继续追问或换问题

**示例对话：**
```
学生："未来3年收入增长率大概是多少？"
管理层："嗯... 我们内部讨论过，2026到2028..."
         [逐字显示，带光标闪烁]

学生："那销售费用会增加吗？"
管理层："现在是10%左右，2027年铺渠道..."
         [继续流式显示]
```

---

### 📋 模式二：一键问答

**特点：**
- 上传所有问题，一次性回答
- 流式显示结构化分析
- 格式化输出（识别结果+分析+提示）
- 适合整理完整访谈记录

**使用场景：**
- 准备好完整问卷
- 需要系统化的回答
- 最终整理访谈报告

**使用方法：**
1. 在文本框输入所有问题（或上传文件）
2. 点击"一次性回答所有问题"
3. 观看管理层流式生成完整回答
4. 每个问题都有三段式分析

**输出格式：**
```
---
📌 识别结果：（管理层说的话）
💡 分析解释：（业务含义）
🎯 模型提示：（如何使用这个信息）
---
```

## 💡 使用技巧

### 对话模式技巧：

1. **连续追问**
   ```
   第一问："产品1增长率？"
   → 得到回答
   第二问："那毛利率呢？"（AI会记住上下文）
   ```

2. **快捷发送**
   - 按 `Enter` 发送
   - 按 `Shift + Enter` 换行

3. **清空对话**
   - 点击"🗑️ 清空对话"重新开始

### 一键问答技巧：

1. **问题格式**
   ```
   1. 未来3年收入增长率？
   2. 销售费用占比变化？
   3. 资本支出计划？
   4. 毛利率预期？
   5. WACC设定？
   ```

2. **文件上传**
   - 支持 `.txt`、`.doc`、`.docx`
   - 自动读取到文本框

3. **等待完成**
   - 流式输出过程中会实时更新
   - 看到"加载"消失即完成

## 🔧 技术实现

### 流式输出原理：
1. API 调用使用 `stream: true` 参数
2. 使用 Server-Sent Events (SSE) 接收数据
3. 实时更新 DOM 显示内容
4. 自动滚动保持可见

### 性能优化：
- 使用 ReadableStream API
- 增量式 DOM 更新
- 避免频繁重绘

## ❓ 常见问题

**Q: 为什么看不到打字效果？**
A: 确保使用的是 `index_v2.html`，并且网络连接正常。

**Q: 流式输出中断了怎么办？**
A: 刷新页面重试，或检查 API Key 是否有效。

**Q: 可以保存对话记录吗？**
A: 对话模式的历史保存在内存中，关闭页面会丢失。建议手动复制重要内容。

**Q: 两种模式可以切换吗？**
A: 可以随时点击顶部按钮切换，但对话历史不会保留。
