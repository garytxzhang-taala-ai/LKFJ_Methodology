# 对外表达

这里是 Taala / LKFJ 所有面向外部受众的真实材料库：内容号、方法论介绍文章、课程与服务宣传、活动物料，以及学生项目案例都集中在这里。这里不使用快捷方式索引；每份可发布或可改写的文件都实际保存在本目录。

## 使用原则

对外表达必须以 `01_方法论/00_AI力基础教育框架（当前项目总说明）.md` 与 `01_方法论/01_AI时代学生能力框架（核心）.md` 为准。当前能力口径为：**人本根基、六块腹肌、持续学习、个性化发展**；AI 是贯穿其中的时代条件，课程以 G / A / P 结构落地。

## 目录

| 编号 | 内容 | 适用场景 |
|---|---|---|
| 00 | 方法论与计划 | 统一传播口径、内容策略、栏目与选题计划 |
| 01 | 方法论介绍文章 | 面向家长、学生或合作方解释教育判断的长文 |
| 02 | 课程与服务介绍 | AI 营、一对一、课程文章、活动计划与 HTML 介绍页 |
| 03 | 活动与专题文章 | 某次论坛、活动、热点或平台版本的成稿 |
| 04 | 栏目内容 Fun Facts | 栏目方法、已发布素材、图文脚本与草稿 |
| 05 | 学生项目案例 | 一对一案例、项目方法、视频与图片素材 |
| 06 | 草稿箱 | 尚未写成成稿的选题、观察、案例与论述种子；由“灵感草稿箱”技能持续归档。 |

课程实施设计、能力框架及内部教学方法仍保留在 `01_方法论` 与 `02_课程`，作为对外材料的事实和方法依据；它们不是宣传稿的存放处。
